# Прогнозирование розничного товарооборота (РТО) | X5 Gradient Growth

> **Конкурс от X5 Tech**: Прогнозирование выручки магазинов сети «Пятёрочка» на основе исторических данных и социально-географических признаков.

| **Интерпретация** | Модель сократила среднюю ошибку прогноза примерно на ~35% относительно базового уровня |


Задача прогнозирования временного ряда была сведена к задаче регрессии с помощью **инженерии лаговых признаков (lag features)**.
